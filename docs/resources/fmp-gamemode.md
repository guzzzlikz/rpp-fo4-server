# fmp-gamemode

**Папка:** `server/fmp-resources/fmp-gamemode`
**Статус:** стандартный gamemode из релиза FMP (`@falloutmp/types` 0.2.5) с нашей правкой хранилища

## Что делает

Базовый roleplay-режим от MafiaHub: регистрация и логин через окно CEF поверх кинематографической камеры, создание персонажа, сохранение позиции и состояния, ранги администрации, чат-команды (`/help`, `/tp`, `/give`, `/pa`, `/time`, `/weather`, `/mines` и др.).

## Наши изменения относительно релиза

| Файл | Изменение | Зачем |
|---|---|---|
| `src/server/database.ts` | `better-sqlite3` заменён на встроенный `node:sqlite` | нативный модуль не загружается в Windows `FMPServer.exe`, см. [known-issues.md](../known-issues.md) |
| `package.json` | удалены `better-sqlite3` и `@types/better-sqlite3`, добавлен `@types/node` 25.9.9 (сервер работает на Node 25.6.1) | то же |

Публичный интерфейс модуля `database.ts` не изменился, остальные файлы gamemode не трогали.
Схема БД та же, поэтому файл `gamemode.sqlite` совместим в обе стороны.

**При обновлении релиза FMP** не перезаписывай эту папку вслепую. Сначала сравни новый gamemode из архива с нашим через `git diff`, потом перенеси правки.

## Хранилище

- Файл: `server/fmp-data/gamemode.sqlite`, путь отсчитывается от рабочей папки сервера. Используется режим WAL, поэтому рядом лежат `-wal` и `-shm`.
- Миграции схемы хранятся в массиве `kMigrations`; номер применённой версии записан в `PRAGMA user_version`. Новую миграцию добавляй только в конец массива.
- Создание аккаунта вместе с персонажем идёт одной транзакцией: если имя персонажа занято, аккаунт тоже не создаётся.

## Админы и ранги

Ранг хранится в аккаунте, в базе `fmp-data/gamemode.sqlite`. **Имя аккаунта = ник, с которым игрок подключился** (`nick=` в ссылке `fmp://`), а не имя персонажа.

| Ранг | Число | Что даёт |
|---|---|---|
| `player` | 0 | `/help`, `/char`, RP-чат: `/me`, `/do`, `/s`, `/b`, `/ooc`, `/pm`, `/pay` |
| `moderator` | 1 | + `/a` (чат персонала), `/kick`, `/goto`, `/gethere` |
| `admin` | 2 | + `/tp`, `/give`, `/time`, `/timescale`, `/weather`, `/pa`, `/xp`, `/level`, `/perk`, `/special`, `/value`, `/caps`, `/look`, `/outfit`, `/kill`, `/fire`, `/items`, `/mines` |
| `owner` | 3 | + `/setadmin` (выдавать ранги из игры) |

### Как назначить первого админа
1. Игрок заходит на сервер со своим ником (`fmp://<IP>:27015?nick=Yaroslav`) и **регистрируется** в окне логина. Пока аккаунта нет, назначить ранг нельзя.
2. В **консоли сервера** (окно `FMPServer.exe`):
   ```
   setadmin Yaroslav owner
   ```
   Ранг можно указать именем или числом: `owner` или `3`.
   **Ожидается:** `Yaroslav is now owner`. Если игрок онлайн, ему придёт сообщение `You are now owner.`, и ранг сработает сразу, перезаходить не нужно.
   Если пишет `No account named …`, аккаунта с таким ником нет: проверь ник и что регистрация прошла.
3. Дальше owner выдаёт ранги прямо из игры: `/setadmin <ник> <ранг>`. Снять ранг: `/setadmin <ник> player`.

**Проверка:** в игре `/help` показывает `Commands (owner): …` со списком админских команд.

## Консоль сервера

| Команда | Действие |
|---|---|
| `setadmin <аккаунт> <player\|moderator\|admin\|owner>` | выдать ранг; аккаунт = ник игрока |

## Как проверить

### Без игры (только сервер)
1. Запусти `server\FMPServer.exe`.
   **Ожидается** в логе:
   ```
   [fmp-gamemode] database fmp-data/gamemode.sqlite at schema 4
   Started JS resource: fmp-gamemode
   ```
   и **нет** строки `Failed to start resource fmp-gamemode`.
2. Введи в консоли `setadmin nobody 1`.
   **Ожидается:** `[fmp-gamemode] No account named nobody`. Это значит, что запрос к БД выполнился.
3. Должен появиться файл `server\fmp-data\gamemode.sqlite`.

Проверено 2026-11-08: сервер запускался с gamemode, кроме того, скомпилированный `database.js` прогнан отдельным скриптом на временной БД. Скрипт проверил создание и поиск аккаунта, откат транзакции при занятом имени персонажа, `setAdminLevel`, сохранение и чтение персонажа, `COALESCE` для документа персонажа.

### С клиентом Fallout 4
1. Подключись к серверу. **Ожидается:** окно логина поверх пролёта камеры.
2. Зарегистрируйся (пароль и имя персонажа), пройди создание персонажа.
3. Перейди в другое место, выйди и зайди снова с тем же паролем.
   **Ожидается:** логин принят, персонаж появляется там, где вышел, с той же внешностью.
4. В консоли сервера выполни `setadmin <твой ник> 3`, затем в игре `/help`.
   **Ожидается:** в списке появились админские команды.

## Известные ограничения
- `node:sqlite` в Node 25 ещё помечен как release candidate. API стабильный, но при обновлении релиза FMP со сменой версии Node стоит пройти проверку выше заново.
