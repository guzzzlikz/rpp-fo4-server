# fo4-server

Сервер Fallout 4 на [Fallout Multiplayer](https://docs.fallout.mp/).

Windows-сервер лежит в репозитории целиком: после `git clone` можно сразу запускать **`start-server.cmd`**.

> Папка должна лежать по латинскому пути, например `C:\fo4-server`, а не на рабочем столе пользователя «Пользователь»: иначе сервер не загрузит ресурсы.
Клиента и Linux-сервера в репо нет, их берут из архива релиза FMP.
Установка, сборка и запуск описаны в [docs/getting-started.md](docs/getting-started.md), оглавление документации в [docs/README.md](docs/README.md).
